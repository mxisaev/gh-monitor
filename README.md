# GH Monitor (DeployTray)

Монитор активных GitHub Actions в системном трее Windows 10/11.

## Запуск

Один раз установите GitHub CLI и войдите в аккаунт:

```powershell
winget install --id GitHub.cli --exact
# После установки откройте новый терминал.
gh auth login
```

В PowerShell из папки проекта:

```powershell
cd C:\Soft\DeployTray
.\gh-monitor.cmd --check
.\gh-monitor.cmd
```

Обычный запуск работает в фоне и возвращает управление терминалу.
При запуске открывается окно настроек. Повторный запуск показывает настройки
уже работающего экземпляра. После закрытия окна монитор остаётся в трее.
Можно также дважды нажать `gh-monitor.cmd` или `Start.vbs` в Проводнике.
Из любой папки PowerShell: `& 'C:\Soft\DeployTray\gh-monitor.cmd'`.
В cmd.exe из папки проекта достаточно `gh-monitor.cmd`.

Для запуска с выводом ошибок в терминал:

```powershell
.\gh-monitor.cmd --console
```

В этом режиме терминал занят до закрытия приложения. Проверка `--check`
проверяет наличие GitHub CLI, авторизацию и компиляцию, затем завершается.
Дополнительный .NET SDK не нужен: используется встроенный .NET Framework.

## Использование

Найдите значок **GH** с чёрными буквами возле часов (он может быть скрыт под стрелкой `^`).
Правый клик → **Settings**: добавьте репозитории `owner/repo`, каждый с новой строки.
По умолчанию показываются все workflow. Необязательный фильтр выбирает их по имени:
например, `deploy` исключит workflow с именем `Promote PKee Marta to itland`.
Оставьте поле пустым, чтобы видеть все активные запуски.

Каждый активный запуск получает отдельный значок с первыми тремя буквами заголовка.
Серые буквы — ожидание (`queued`, `waiting`, `pending`, `requested`),
жёлтые — выполнение (`in_progress`). Цвет обновляется при смене статуса.
Фон значков прозрачный и совпадает с фоном панели задач.
Двойной клик открывает запуск на GitHub. Завершённые запуски исчезают.
Красный GH означает ошибку проверки; **Refresh** запускает проверку вручную.
После успешного завершения отслеживаемого workflow буквы **GH** зелёные
до истечения 5 минут с момента завершения. Следующий успех продлевает срок.
Ошибка связи имеет приоритет и показывает красный GH. Зелёный цвет относится
ко всем workflow, которые проходят фильтр, а не только к job с названием deploy.
Правый клик → **Exit** закрывает приложение. Повторный запуск не создаёт второй экземпляр.

Для автозапуска: Win+R → `shell:startup` → поместите туда ярлык на `Start.vbs`.
Настройки сохраняются рядом с исходниками в `config.json`, который исключён из Git.
Токены обслуживает GitHub CLI; приложение не сохраняет их в конфигурации.
